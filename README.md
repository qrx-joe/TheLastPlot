# 最后一块地 The Last Plot

一款以空间规划与外部性取舍为主题的 3D 益智游戏。当前完成 S2：在 5×5 地块中编辑建筑布局，即时观察经营期净收益、污染与满意度，提交后查看评分、称号及未达标原因。建筑目前仍为几何占位模型，下一阶段接入真实 Lux3D GLB。

## 本地运行

需要 Node.js 22.12 及以上的 22.x、24.x 或 26+（本次使用 24.13.0），以及 npm；该范围同时满足 Vite 和 Vitest。依赖版本由 package-lock.json 固定。

```sh
npm ci
npm run dev
```

终端会显示本机预览地址。浏览器需支持 WebGL2。

- 选建筑后点击格子，以该格为西南角原点放置；绿色预览为合法，红色预览附带拒绝原因。
- 点击已有建筑，使用「移动」或「删除」；移动时原建筑保留到合法落点确认。Esc 或「取消」退出当前操作。
- 删除全额退回建造预算；「撤销一步」只恢复最近一次成功的布局变更，无重做。
- 公园与商店二选一，更换时先删除旧设施。「重新开始」清空布局及撤销记录。
- 橙色斜线格表示固定西风向东的污染区域；选中住宅可查看满意度的基础值、污染扣罚与设施加成。
- 放齐 1 工厂、2 住宅和 1 项设施即可提交；满意度至少 70、当期净收益至少 25 才达标。「继续调整」或 Esc 返回原布局，并保留单步撤销。
- 拖动旋转相机、滚轮缩放；超过 5 CSS 像素的拖动不会建造。「复位视角」恢复初始相机。

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

生产构建输出到 dist；preview 仅用于本地验收。当前尚未部署。

## 结构

- index.html 与 src/styles：静态界面及样式。
- src/main.ts：创建场景、绑定入口事件和卸载清理。
- src/data：单一配置源。
- src/domain：建筑类型、占地、放置合法性、数量/设施互斥、预算和经济结算纯规则；污染预览与住宅扣罚复用同一判定。
- src/scene：相机、灯光、地块、坐标转换、拾取、占地/污染预览、世界方向标记和几何占位建筑；只有一个渲染循环。
- src/state/gameStore.ts：不可变状态、动作校验、单步撤销、编辑/结果阶段与派生指标读取接口。
- src/ui/HUD.ts：建筑选择、数量、即时指标、编辑与提交结果；通过 store 读写，不复制规则。
- tests：5 个文件、79 项定向测试，覆盖编辑、经济公式、污染边界、称号与结果状态；最多使用两个 Vitest worker。
- [开发文档](docs/README.md)：产品规则、技术规范和阶段验收。
- [S0 验收记录](docs/reports/2026-11-08-s0-bootstrap.md)：实际构建、浏览器检查和当前限制。
- [S1 验收记录](docs/reports/2026-11-08-s1-grid-placement.md)：编辑流程、测试结果和当前限制。

当前建筑均为原生几何占位模型；真实 Lux3D 核心建筑将在 S3 接入并记录来源。当前已能完成单关规划与结算，尚未完成正式任务引导、真实资产、部署及比赛材料。
