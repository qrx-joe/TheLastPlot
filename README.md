# 最后一块地 The Last Plot

一款以空间规划与外部性取舍为主题的 3D 益智游戏。当前完成 S4：从小镇委托开始，在 5×5 地块中安排工厂、住宅与一项设施，观察收益、污染和满意度，提交后查看评分及未达标原因。支持移动、删除、单步撤销和继续调整。工厂使用真实 Lux3D 贴图 GLB；住宅、公园和商店仍使用有明确提示的几何占位模型。

## 本地运行

需要 Node.js 22.12 及以上的 22.x、24.x 或 26+（本次使用 24.13.0），以及 npm；该范围同时满足 Vite 和 Vitest。依赖版本由 package-lock.json 固定。

```sh
npm ci
npm run dev
```

终端会显示本机预览地址。浏览器需支持 WebGL2。

- 首次打开先阅读委托并点击「开始规划」；游戏中可随时查看「委托与玩法」，不会改变当前布局、移动操作或撤销记录。
- 选建筑后点击格子，以该格为西南角原点放置；绿色预览为合法，红色预览附带拒绝原因。
- 点击已有建筑，使用「移动」或「删除」；移动时原建筑保留到合法落点确认。Esc 或「取消」退出当前操作。
- 删除全额退回建造预算；「撤销一步」只恢复最近一次成功的布局变更，无重做。
- 公园与商店二选一，更换时先删除旧设施。「重新开始」清空布局及撤销记录。
- 橙色斜线格表示固定西风向东的污染区域；选中住宅可查看满意度的基础值、污染扣罚与设施加成。
- 放齐 1 工厂、2 住宅和 1 项设施即可提交；满意度至少 70、当期净收益至少 25 才达标。「继续调整」或 Esc 返回原布局，并保留单步撤销。
- 拖动旋转相机、滚轮缩放；超过 5 CSS 像素的拖动不会建造。「复位视角」恢复初始相机。
- 界面逐类显示模型状态。工厂加载失败时自动回退为几何体，并显示失败提示；没有提供的可选模型不会发起请求。

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

生产构建输出到 dist；preview 仅用于本地验收。正式试玩：[the-last-plot.vercel.app](https://the-last-plot.vercel.app/)。

## 演示与部署准备

已准备 160 秒的本机生产构建实录（中文字幕、无配音）和 6 页项目报告 PDF。录像展示失败后继续调整、公园与商店两种通关方案、移动、撤销和删除退款。文件与验证范围见[发布与演示材料记录](docs/reports/2026-11-08-release-preparation.md)。

Vercel 配置使用 Vite、`npm ci`、`npm run build`，发布目录为 `dist`。已部署至 [the-last-plot.vercel.app](https://the-last-plot.vercel.app/)，线上 5 项资源内容校验与两种通关方案通过。后续在项目根目录运行 `vercel --prod` 发布，再用 `npm run verify:release -- --url https://the-last-plot.vercel.app/` 及浏览器检查结果。

## 结构

- index.html 与 src/styles：静态界面及样式。
- src/main.ts：创建场景、绑定入口事件和卸载清理。
- src/data：规则配置、已提供的模型清单与模型显示尺寸上限。
- src/domain：建筑类型、占地、放置合法性、数量/设施互斥、预算和经济结算纯规则；污染预览与住宅扣罚复用同一判定。
- src/scene：相机、灯光、地块、坐标转换、拾取、占地/污染预览、世界方向、GLB 缓存/克隆与占位回退；模型归一化不改变逻辑占地，只有一个渲染循环。
- src/state/gameStore.ts：不可变状态、动作校验、单步撤销、intro/playing/result 阶段与派生指标读取接口。
- src/ui：HUD 展示建筑选择、数量、即时指标、编辑和结果；MissionDialog 管理首次委托与查阅说明，通过 store 派发 START，不复制规则。
- tests：8 个文件、99 项定向测试，覆盖开始边界、编辑、相机复位、经济规则、结果状态和资产路径/归一化/缓存/回退/释放；最多使用两个 Vitest worker。
