# 项目起源与决策留档

记录《最后一块地》立项之前的关键决策链，供复盘和答辩叙述使用。原始依据为 2026-11-06 的 ChatGPT 对话（标题"群核and谷歌"，分享链接 `chatgpt.com/share/6af00d67-92a0-83ec-8282-32c90e402e68`）。完整导出件在 `output/chatgpt-origin-20261106/transcript.md`（本地留档，不进版本提交）。

## 背景：Aholo 全球 3D AI 黑客松

**TJAI × 群核科技 × Aholo 全球 3D AI 黑客松**：线下 Workshop 11月7-8日上海站，全球赛提交截止 11月19日 19:00。参赛要求：必须使用 Lux3D 生成 3D 资产、交付可实际运行的 3D Demo；线下各站前两名直通黑客松 TOP50。项目以此为参赛主线。

## 选题迭代过程

1. **3D 说明书**（最初方案）：把家电说明书做成 3D 交互，解决中老年人看不懂纸质说明书的问题。被用户主动否决，理由：通用大模型（豆包、小微）可以取代，**没有壁垒**。
2. **LifeQuest 3D**：游戏方向的第一个 PRD（v0.1），被用户以"不好玩、可被通用大模型取代"否决。
3. **头脑风暴阶段**：送自己去坐牢、办公室协作模拟、"求求你开除我"、3D 版消消乐、贪吃蛇/植物大战僵尸等经典 3D 化、翻面棋/六面世界、"六面荒诞事务所"。
4. **收敛提问**：用户问"3D 与经济学怎么结合"。ChatGPT 提出核心设计原则：让玩家**通过摆放、移动、交换物体体验经济学**（稀缺、机会成本、外部性），而不是在 3D 场景里做选择题。
5. **冲刺定案**（11月7日晚）：用户给出硬约束——"明天上午 12 点之前做出来并提交"。ChatGPT 进入冲刺交付模式，停止发散，推荐《最后一块地》（The Last Plot）：在一块有限 3D 土地上摆放工厂、住宅、设施，在预算、利润、满意度与环境之间取舍。用户拍板。

## 名字来历

《最后一块地 / The Last Plot》由 ChatGPT 在冲刺推荐方案中首次提出，用户采纳。后续单独评估（对话最后一条）：8/10，建议保留——有悬念、与核心玩法契合（土地稀缺、机会成本、利益冲突）；缺点是辨识度（可能被误认为房地产游戏）。建议的副标语"每一块土地，都有它的代价"未正式采用。

## 与最终实现的差异（对话假设 → 实际落地）

- 技术栈：对话推荐 **Godot 4** → 实际采用 **Vite + TypeScript + Three.js**（浏览器免安装，符合 Workshop 现场演示）。
- 对话阶段为通宵冲刺单一版本 → 实际按 S0–S5 阶段验收推进（见 docs/reports）。
