## 生成与文件检查

- 渠道沿用已登录的 Lux3D 中国站网页。设置为卡通参考图、标准版网格、100K 目标面数、PBR 开启、单图、不做四视图增强。实际面数以文件检查为准。
- 网站任务卡使用“Lux3D-G1 图生 3D 起始流”标签，住宅预览文件名为 `lux3d_g1_33246.glb`；不据此推断 API 版本，也不把文件名中的数字冒充独立核验过的提供方任务 ID。
- 住宅 ZIP 中的 `MODEL.glb` 只有 2×2 占位贴图及分离的原始材质图；改用同一已完成任务的原生 GLB 导出，得到内嵌两张 2048×2048 PNG 的 `textured.glb`。这是下载交付处理，没有追加生成或收费重试。游戏仅使用后者。
- 原始下载包、GLB、参考图、逐项预算与执行记录存放在 Git 忽略的 `output/asset-expansion-20261108/`。保留源文件，不覆盖工厂。
- 页面余额在商店参考图生成期间出现外部变动，原因未核实；继续按本批 96 积分上限记账，不由余额变化扩大授权。
