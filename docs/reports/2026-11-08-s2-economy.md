# S2 经济规则与规划结算验收

日期：2026年11月8日。结果：S2 完成，可继续 S3。已能在本地完成规划、观察空间效应并提交结算；当前全部建筑仍为 Three.js 几何占位模型，本阶段没有生成或接入真实 Lux3D GLB。

## 实现与结构影响

输入/HUD → gameStore.dispatch → 当前布局 → evaluateCity → HUD/结果窗口；污染覆盖层读取与住宅扣罚共用的纯判定。收益、满意度和分数每次从当前布局重算，不累加历史结果。

- data/gameConfig.ts：补齐 PRD 原值的建筑经营期净收益、设施加成、污染阈值、通关目标和评分称号配置，没有调整冻结数值。
- domain/economy.ts、grid.ts、validation.ts、types.ts：逐工厂占地格判定下风向、地图内污染集合、占地间最小曼哈顿距离、住宅明细、平均值、完整性、评分和称号。完整但非法的布局不能结算成功；无住宅返回 null，已有一栋时按该栋显示，布局不完整不授分。
- state/gameStore.ts：新增 getEvaluation、SUBMIT 和 CONTINUE；只有完整布局可进入结果，未达经济目标也显示失败原因。结果阶段拒绝编辑，继续调整保留布局与撤销快照；RESET 清空布局及快照。
- scene/SpatialOverlay.ts、ScenePresenter.ts：显示污染格、世界北向与西风向东箭头；合法工厂预览使用候选位置，无候选时恢复已放工厂。共享材质/几何体，销毁时释放纹理、箭头与其他资源。
- PlacementController.ts：结果阶段停止拾取操作和放置预览，Esc 交给原生结果窗口处理。
- HUD.ts、main.css：即时净收益/平均满意度、住宅扣罚与加成明细、提交条件、原生模态结果窗口及继续/重置入口。界面不重写经济规则。

入口组装、相机、坐标约定、几何占位建筑、依赖与锁文件均未改动；S3 的资产加载和 S4 的任务引导未提前实施。为验证 S2 状态闭环，结果窗口已提供基础可操作界面，完整视觉与任务说明仍属于 S4。

- 未独立验证 Chrome/Edge 稳定版矩阵、真实手机/触摸、FPS、GPU 内存或完整可访问性；本轮浏览器证据限于上述桌面环境。

- 方向文字在部分视角可能与建筑投影重叠；当前可通过旋转辨认，视觉精修留在 S4。
- 尚未部署，也没有真实模型加载、生成证据或比赛交付材料；本轮不宣称完成 Lux3D 核心素材要求。
- S3 优先将真实 Lux3D 工厂 GLB 用作可放置、移动、删除的核心建筑；住宅可用一个模型克隆两次，商店可选，公园允许继续使用原生几何体。先完成一个模型的加载与来源验收，再考虑更多资产。
