# S4 玩家界面与闭环验收

日期：2026-11-08。阶段基线：S3 提交 `3c602fb`。本阶段仅完成 S4，没有执行发布、远程推送或参赛提交。

## 实现与结构影响

- 首次进入 `intro`，任务说明列出预算 80、1 工厂、2 住宅及二选一设施，目标为平均满意度 ≥70、净收益 ≥25；点击开始才进入 `playing`。未开始不能选择、编辑或提交。RESET 仍回到空的 playing，不再次强制阅读委托。
- 新增 MissionDialog，游戏中可查阅风向、设施距离、费用与操作说明。说明中的 Esc 只关闭查阅，不取消正在移动的建筑；首次说明中的 Esc 保持说明。开始后设置焦点但不滚动窄屏页面。
- HUD 显示三项指标、建筑进度、费用/占地/贡献、逐类 Lux3D/占位/失败状态。已有设施时另一卡禁用并说明先删除，不自动替换；完整原因仍保存在卡片提示中。选中住宅可查看满意度构成。
- 桌面限定游戏区域高度，较长说明在侧栏内滚动，预算及撤销/重置/反馈/提交固定可见；窄屏上下排列。为窄画布调整相机取景，将指北文字移出工厂烟囱遮挡区。箭头仍使用世界坐标，未修改风向或拾取规则。
- 结果弹窗保留成功、失败差额、评分、解释、继续调整及重置。未齐全不显示评分，无住宅显示「—」，一栋时显示住宅 1/2。

需求经过入口 → 说明/HUD → store → 既有 domain 与 scene。实际修改入口、UI/CSS、开始状态与少量相机/标注显示；domain 仅扩展 START 动作类型。经济公式、放置校验、坐标转换、拾取优先级和 AssetLoader 未改，规则仍由配置及纯函数负责，没有增加依赖或生成新模型。

## 范围与剩余限制

S4 手册要求的任务、建筑卡、指标、世界方向、放置反馈、结果、错误、取消、撤销/重置、设施互斥、空值与失败保留历史均有实现和对应验证。此结论不等于线上验收或真人试玩结论。

- 未部署，未验证线上网址或 CDN；非根 base 的真实 GLB 接入沿用 S3 证据，本阶段没有重复该项浏览器测试。
- 仍只有工厂是真实 Lux3D 模型，其余为明确标注的几何占位。工厂约 7.29 MB、2K 贴图与包体积警告仍待性能评估。
- 未测真实手机、完整无障碍、低配 GPU/FPS；未邀请首次玩家验证 30 秒理解、2–4 分钟完成等体验目标。
- 窄屏需在建筑卡与地块之间滚动；小高度桌面需在侧栏查看完整说明。普通点击仍优先建筑占地代理，遮住后方空格时可旋转视角或点击露出的部分。
- 本地预览及故障注入服务在验收后停止；复现使用 `npm run build`、`npm run preview`。
